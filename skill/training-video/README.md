# Training video

Use this skill to make a narrated or captioned how-to video from real screens in a web application. It produces a video with a short explanation of each step and highlights the controls the viewer needs to use.

Tell the assistant who the video is for, what viewers should learn, which application to show, and whether to use narration or captions. Review the proposed outline before screen capture or voice generation begins. Decide how to handle any private information visible on screen; you can hide all of it, hide only certain fields, skip those screens, or leave it showing.

Before writing the script, the assistant lists every tab and main button in the application, so the outline covers the whole application or names what it leaves out. It rewrites the spoken lines in plain English, and it tests how the voice says names before paying for the full narration. If one line comes out wrong, it replaces that line only.

For a finished example, watch the [La Maison app walk-through](https://github.com/RachaelQuisel/training-videos/blob/main/la-maison-scheduling-page-2026-11-11/LaMaison-App-Walk-through-Video.mp4), a video of a Zite scheduling app for cleaners and property inspectors.

The working instructions are in [SKILL.md](SKILL.md). The bundled scripts help capture screens, build slides, align narration, assemble the video, and check the result. The instructions describe the software and account connections each route needs.

RachaelQuisel maintains this skill. Its files are registered in the repository's maintenance inventory. The scheduled maintenance check does not run a complete video build or verify voice-service access. Those capabilities remain unverified by that check.
