How it gets made

One command in Claude Code and a link to the app. The skill does the rest and reports what it checked.

  1. Read the live appEvery tab and button is listed first, so the script covers the whole app.
  2. Write the scriptPlain English, one idea per slide, approved before anything costs money.
  3. Capture the screensRequests that would save data are blocked. Buttons that write are never pressed.
  4. Test the voiceOne short clip with every name in it, before the full narration is bought.
  5. Build the slidesA yellow box drawn from the measured position of each button, plus a caption.
  6. Time it to the voiceEvery spoken word gets a timestamp, and each slide lands just before its first word.
  7. Check the resultThe finished audio is transcribed and compared to the script, and frames are pulled to match.
